#### A. 런타임 메트릭 (Runtime Metrics)

- **`process.runtime.cpu.utilization`**: CPU 사용률
    
- **`process.runtime.memory.usage`**: 메모리 사용량 (RSS, VMS 등)
    
- **`process.runtime.thread_count`**: 활성 스레드 개수
    

#### B. HTTP 메트릭 (HTTP Metrics)

- **`http.server.active_requests`**: 현재 처리 중인 요청 수
    
- **`http.server.duration`**: 요청 처리 시간의 분포 (Histogram)
