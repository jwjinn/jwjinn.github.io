"vLLM 주방장에게 맡기겠다"는 선언은 **`predictor`** 아래에 정의합니다. 사용자가 직접 서버 코드를 짤 필요 없이, 이미지와 명령어만 주면 KServe가 포트(8080 등)와 헬스 체크를 알아서 연결합니다.

- **설정 위치:** `spec.predictor`
    
- **핵심 설정:** `containers` 안에 vLLM 실행 명령어(`args`)를 넣습니다.
***
## 설정

```yaml

spec:
  predictor:
    # [설정 2] 추론 엔진(vLLM) 구동 정의
    containers:
    - name: kserve-container
      image: vllm/vllm-openai:latest
      # KServe가 이 컨테이너를 관리하므로 포트 바인딩 등을 신경 쓸 필요가 없음
      args:
        - "--model=/mnt/models"           # 모델 위치 (아래 스토리지에서 연결됨)
        - "--served-model-name=qwenendpoint"
        - "--trust-remote-code"           # Qwen 모델 필수 옵션
        - "--gpu-memory-utilization=0.9"  # GPU 메모리 사용률 설정
      resources:
        limits:
          nvidia.com/gpu: 1               # GPU 할당

```
