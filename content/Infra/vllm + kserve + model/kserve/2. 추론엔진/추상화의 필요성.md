## 없다면, 개발자가 직접해야 하는 것

1. Python으로 `app.py` 파일을 만든다.
    
2. FastAPI나 Flask 같은 웹 서버 코드를 짠다.
    
3. `POST /predict` 요청이 오면 데이터를 받아서 모델에 넣고 결과를 JSON으로 바꾸는 코드를 직접 짠다.
    
4. 직접 `docker build` 하고 포트(8000번)를 열어준다.
    
- **문제점:** 모델마다 코드가 다르고, 개발자마다 짜는 방식이 달라서 관리가 엉망이 됩니다.
***
## 추상화를 하게 되면:
- **중요성:** 사용자는 복잡한 네트워크 코드, 병렬 처리, API 규격을 고민할 필요가 없습니다.
    
- **표준화:** PyTorch를 쓰든, TensorFlow를 쓰든, vLLM을 쓰든 **외부에서 말 거는 방식(API 요청 포맷)이 똑같아집니다.** (Standard Inference Protocol).

모델만 가져오게 되면, 포트와 api 통신을 규격화된 버전으로 제공을 하게 한다.
