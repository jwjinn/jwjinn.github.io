Pod가 뜰 때 모델 파일을 자동으로 준비해 주는 기능은 **`storageUri`** 한 줄로 끝납니다.

- **설정 위치:** `spec.predictor.model.storageUri`
    
- **핵심 설정:** `pvc://`로 시작하면 PVC에서 가져오고, `s3://`면 S3에서 가져옵니다.
    
- **작동 방식:** KServe가 몰래 `storage-initializer`라는 컨테이너를 먼저 실행해서, `/mnt/models` 경로에 파일을 딱 복사해 놓고 사라집니다.

***
## 설정 예시

```yaml

model:
      modelFormat:
        name: vllm
      runtime: kserve-vllm
      # [설정 3] 스토리지 자동 연결
      # 이 설정 덕분에 직접 mountPath를 잡거나 cp 명령어를 칠 필요가 없음
      # KServe는 이 URI의 내용을 컨테이너의 /mnt/models 에 자동으로 마운트함
      storageUri: pvc://nai-de85c8d8-2656-4676-bebe-b6-pvc-claim/model-files

```
