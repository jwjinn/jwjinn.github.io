새로운 PVC ID 검색 후 디버깅 POD 생성


```shell


cat <<EOF | kubectl apply -f -
apiVersion: v1
kind: Pod
metadata:
  name: debug-storage-check-new
  namespace: nai-admin
spec:
  containers:
  - name: debug
    image: ubuntu:latest
    # 1시간 동안 살아있도록 설정
    command: ["/bin/bash", "-c", "sleep 3600"]
    volumeMounts:
    - name: model-store
      mountPath: /debug-data
  volumes:
  - name: model-store
    persistentVolumeClaim:
      claimName: nai-96141299-40ce-465d-bd4f-cd-pvc-claim
  restartPolicy: Never
EOF

```

- watch
```shell
# * 대신 폴더 자체 용량을 체크
kubectl exec -it -n nai-admin debug-storage-check-new -- watch -n 2 "du -sh /debug-data"

```
